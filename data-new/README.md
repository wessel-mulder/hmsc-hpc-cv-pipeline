# Data layout

- `0-pre/raw/`: supplied starting inputs, source HILDA annual rasters and cached
  CHELSAcruts monthly grid crops. Treat as inputs; do not overwrite them.
- `0-pre/derived/Tr/`: species-level traits, matching audit and descriptions.
- `0-pre/derived/taxonomy/`: IOC rank-based tree, tables and PNG.
- `0-pre/derived/environmental/`: full original-class environmental CSV,
  annual/per-atlas intermediates and current diagnostic figures.
- `2-hmsc/derived/`: S0 forest-split RData and row/species filtering audits.
- `reproducibility/`: rebuild reports, package versions, source/input checksums.
- Other numbered folders: subsequent analysis stages; not regenerated by the
  current preprocessing reproduction command.

See `scripts/0-pre/README.md` for input definitions, preserved choices,
limitations and reproduction commands. Fitted models and large posterior arrays
remain outside this data folder. Source access/publication permissions are a
separate matter from computational reproducibility.
