# Taxonomy Derived Products

Contains taxonomy and pseudo-phylogeny products used by the current HMSC model setup.

- `taxonomy.csv`: taxonomy table used in the preprocessing chain.
- `tree_fromPD.tre`: pseudo-phylogeny tree read by `S1_Model_Definitions.R`.
- `IOC_Names_File_Plus-15.1_wide.csv`: wide IOC-derived taxonomy product retained as provenance.

The exact upstream IOC workbook is not fully bundled here.
