PNG exploratory figures of X_environment.csv, generated by plot-derived-environment.R.
Every map shows all 2,165 supplied cells for each atlas; no survey coverage filter is applied.
Absolute panels share one scale across the three atlases. Percentage panels use 0-100%.
Relative means within-atlas z scores, using the same non-missing sites across all atlases for each variable.
Relative maps show spatial contrasts and remove atlas-wide shifts; compare absolute maps to assess temporal change.
Constant variables have undefined relative values and are shown in grey; scaling parameters are in relative-map-scaling.csv.
Climate point clouds use shared complete sites across atlases, with separate matching by season.
Climate Atlas 3 uses 2014-2016; HILDA Atlas 3 uses 2014-2017. Missing values are never filled.
Land-only percentages differ from whole-cell percentages. LULC proportions are not plotted again because pct columns show the same information.
Original crop and forest subclasses are included; other original classes duplicate broad classes and are not plotted twice.
Area/coverage diagnostics and ID/year metadata are excluded from environmental-variable maps.
Precipitation differs materially from legacy processing; these figures describe the regenerated source data.
