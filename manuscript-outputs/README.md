# Manuscript Outputs

This folder contains publication-facing outputs promoted from working locations.

- `figures/main/`: current main manuscript figures.
- `figures/methods/`: methods/supporting figures used to describe analysis filtering.
- `figures/supplement/`: current supplementary figures.
- `tables/methods-audit/`: supplementary methods tables and source CSVs.
- `supplementary-material/`: compiled supplementary DOCX files that embed retained figure PNGs.

Exploratory diagnostic figures, especially `z-*` outputs, are intentionally not promoted here unless they become manuscript or supplement material.
